# Portfólio & Currículo Interativo — React & Next.js

Portfólio e currículo acadêmico/profissional desenvolvido com **React 18** e **Next.js 14 (App Router)**, com design system autoral em **CSS3 Glassmorphism** e integração em tempo real com **3 APIs REST públicas**.

## 🚀 Páginas Desenvolvidas

1. **Home (`/`)**: Apresentação profissional, resumo de qualificações, métricas de carreira e painel ao vivo de APIs integradas.
2. **Sobre (`/sobre`)**: Biografia do desenvolvedor, matriz de habilidades e documentação detalhada de **todas as tecnologias, bibliotecas, hooks e módulos** utilizados para desenvolver o aplicativo.
3. **Experiência Acadêmica (`/experiencia-academica`)**: Linha do tempo da formação acadêmica, cursos de especialização e pilares de pesquisa.
4. **Experiência Profissional (`/experiencia-profissional`)**: Histórico de atuação profissional, conquistas técnicas e stacks utilizadas em cada experiência.
5. **Projetos Desenvolvidos (`/projetos`)**: Vitrine de projetos em destaque e listagem dinâmica consumindo a **API oficial do GitHub** com busca instantânea e filtro por linguagem.

## 🌐 Integrações com APIs Públicas

- **GitHub REST API (`api.github.com`)**: Busca dados reais do perfil e lista todos os repositórios públicos na página de Projetos.
- **Open-Meteo Weather API (`api.open-meteo.com`)**: Exibe a temperatura, umidade e velocidade do vento em tempo real da cidade do desenvolvedor (Recife, PE).
- **DummyJSON Quotes API (`dummyjson.com/quotes/random`)**: Permite carregar novas citações inspiradoras sob demanda.

## 🛠️ Tecnologias & Módulos Utilizados

- **React 18** (`react`, `react-dom`)
- **Next.js 14** (`next/link`, `next/navigation`, App Router)
- **Lucide React** (`lucide-react` para ícones vetoriais SVG)
- **CSS3 Moderno** (Variáveis CSS, Glassmorphism `backdrop-filter`, CSS Grid, Flexbox e animações)

## 📦 Como executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000` no navegador.
